# Flickr public-photo source qualification

The public tag feed is an additional social-photo source, outside the Imgflip popular-template catalog. It uses [Flickr's documented public feed](https://www.flickr.com/services/feeds/docs/photos_public/) and the [oEmbed photo response](https://oembed.com/) to obtain the image URL advertised by Flickr. It never fabricates an original-file URL or upgrades a thumbnail suffix by guessing. The current provider returns approximately 1024px images for these requests; requested dimensions are bounded to 1600px.

Topics are Flickr tags. Use `cat` or `nature`, or a comma-separated tag set such as `cat,pet`; all supplied tags must match. This is a bounded recent feed, with no invented pagination or hidden full-catalog API. A new daily result depends on matching uploads. Public metadata does not establish reusable image rights.

The worker validates exact Flickr post/media hosts, photo identity, response size, decoded bytes, duplicates, total count and daily budget. Foreign media URLs and a response for a different photo ID are rejected. Access denial/rate limits stop normally, and removed/private oEmbed records are skipped. Original post links remain in provenance. No API key, sign-in or AI generation is used by this adapter.

On October 29, HandNavigate's own local HTTP service collected **20/20 distinct decoded photos** across `cat` and `nature`. [Safe evidence](../service/evidence/flickr-local-20261029.json) records source links, dimensions and hashes, without image bytes. The exact Railway host then completed a separate 20/20 batch and every stored Supabase image passed independent checksum/decoded-image read-back: [hosted evidence](../service/evidence/flickr-hosted-20261029.json). The daily animal plan was changed to cat/dog tags only after that acceptance; multi-day natural runs remain open.

The 0.8.0 release remains a separately verified custom-source build. Flickr is added in the subsequent 0.9 source and requires that updated worker; an older worker cannot claim Flickr jobs. No collected file is automatically approved, published or admitted into generation.
