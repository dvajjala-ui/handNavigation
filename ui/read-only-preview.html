Owned-portal quick start

Separate terminal, same runtime directory:

python -m handnavigate portal

After inspecting and approving its profile:

python -m handnavigate connect owned-report-portal

python -m handnavigate export owned-report-portal --topic architecture

Commands above are wrapped for display; enter each as one line. Use a private terminal for the hidden passphrase prompt.

Environment check:

python -m handnavigate doctor

Exit code 2 means browser qualification is incomplete. Do not change administrator policy to bypass a restriction.
